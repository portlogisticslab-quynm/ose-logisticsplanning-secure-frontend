# Frontend

Vanilla HTML/CSS/JavaScript client. It reads Excel files in the browser, calls the backend solver API, and renders tables, charts, GIS-style views, and animation.

## Files
- `index.html`: page structure
- `css/styles.css`: UI styles
- `js/config.js`: backend API URL
- `js/app.js`: application logic
- `assets/examples/`: sample workbook
- `assets/images/`: guide and UI images

For separate hosting, edit `js/config.js` and set `API_BASE_URL`.
